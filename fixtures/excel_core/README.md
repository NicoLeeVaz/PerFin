# Synthetic fixtures for the core Excel shell (task 2c)

Everything in this folder is **synthetic**. No real person, account or institution is
represented. Card/account identifiers are aliases; there are no account numbers.

| Path | What it is |
| --- | --- |
| `ledger_bundle.synthetic.json` | `contracts/examples/valid/ledger_household.json` plus a June statement for `card:beta` and an `in_progress` reconciliation `r002` (difference 2500), validated by `perfin_contracts`. |
| `staging_batch.synthetic.json` | `contracts/examples/valid/staging_batch_card.json` plus rows 6-10 whose descriptions start with `+`, `-`, `@`, TAB and CR (formula-injection cases). |
| `reports/rpt_*.csv` | The six report tables the core shell refreshes, in the exact `report_tables.json` columns and CSV dialect (UTF-8 without BOM, CRLF, minimal RFC 4180 quoting, empty = null, `TRUE`/`FALSE`, integer minor units). Generated by `python3 tests/excel_core/fixture_gen.py`; a test fails if they drift. They stand in for the 2b report export, so 2c does not depend on 2a/2b. |
| `modules/<module_id>/module_manifest.json` | Mock module manifests (payoff = the contract example; statements = a 4b-shaped mock). Tests add tiny generated workbooks next to them in a temporary folder. |
| `commands/<uuid>.json` | A draft in exactly the shape `PerFinCommands.bas` writes (one line, ASCII with `\u` escapes, CRLF), used to test `command promote`. |

Fixture conventions that the contract leaves open (recorded as tracker items in the 2c PR):
`rpt_transactions.reconciled` is TRUE only for transactions included in a **balanced**
reconciliation; `rpt_review_queue.error_codes` joins codes with `;`;
`rpt_card_status.confirmed_payments_minor` sums allocations to the latest statement and
`unpaid_statement_minor = max(statement_closing_owed_minor - confirmed_payments_minor, 0)`;
`utilization_basis_points` is floor(owed × 10000 / limit) and empty when the limit is unknown.
All report figures are as of 2026-06-30.
